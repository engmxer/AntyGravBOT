# 🤖 Telegram Booking Bot Boilerplate (Ядро онлайн-записи)

Готовый шаблон (boilerplate) Telegram-бота для онлайн-записи на услуги (салоны красоты, барбершопы, автосервисы, студии маникюра и любые сервисные компании).

Проект спроектирован по принципу **«Zero-Code Rebranding»**: чтобы запустить бота под новую компанию, достаточно скопировать один YAML-файл с конфигурацией и прописать токен бота в `.env`. Никаких правок в логику кода вносить не требуется!

---

## 🌟 Ключевые возможности

### 1. Для клиентов:
- **Онлайн-запись в 5 шагов**: выбор категории → выбор услуги → выбор мастера (опционально) → интерактивный inline-календарь дат → выбор доступного временного слота → подтверждение.
- **Интерактивный прайс-лист «Услуги и цены»**:
  - Каталог по категориям с удобной пагинацией («◀️ Пред.», «След. ▶️»).
  - Карточка каждой услуги: название, точная цена или диапазон, длительность, описание.
  - Быстрая сортировка по цене (дешевле ⬆️ / дороже ⬇️).
  - Кнопка **«📅 Записаться на эту услугу»** прямо из карточки услуги — сразу переводит в выбор даты и времени с предзаполненной услугой!
- **«Мои записи»**:
  - Просмотр всех предстоящих записей.
  - **Отмена записи** в один клик.
  - **Перенос записи (Reschedule)** — выбор новой даты и времени без отмены текущей брони.
- **«О компании»**: адрес, кликабельная ссылка на Яндекс/Google карты, телефон, Instagram, сайт, график работы с учетом выходных и перерывов.
- **Напоминания о визите**: автоматическая отправка клиенту напоминания за $N$ часов через APScheduler.

### 2. Для администратора:
- **Команда `/admin`** с доступом по Telegram ID.
- **Просмотр записей**: на сегодня и на ближайшие 7 дней (с ФИО, телефонами, мастерами и статусами).
- **Отмена любой записи** прямо из админки.
- **Управление прайс-листом без кода**:
  - Просмотр категорий и услуг из БД.
  - Быстрое изменение стоимости услуги (отправкой нового числа в чат).
  - Включение / отключение услуг (скрыть из каталога клиентов).
  - Удаление услуг.
  - Добавление новой услуги через пошаговый FSM-мастер (Название → Цена → Длительность → Описание).
- **Блокировка дней и слотов**: блокировка дат (отпуск, санитарный день, праздники) и снятие блокировки.
- **Уведомления**: мгновенные сообщения в рабочий чат компании о каждой новой записи.

### 3. Архитектура:
- **Python 3.11+**, **aiogram 3.x** с Router и FSM-хранилищем.
- **SQLAlchemy 2.0 (async)** + **SQLite** (для быстрого старта) / **PostgreSQL** (для продакшна).
- **Синхронизация YAML → БД**: при первом старте бот автоматически сидирует каталог из YAML-файла компании в БД. Далее прайс-лист хранится в БД и управляется через админку бота!
- **Мульти-развертывание**: возможность запускать десятки ботов для разных компаний с одним исходным кодом через `docker-compose.multi.yml`.

## 🚀 Быстрый старт за 3 шага

### Шаг 1. Клонирование и настройка окружения
```bash
git clone <repo_url>
cd booking_bot

# Создайте файл окружения:
cp .env.example .env
```

Заполните `.env`:
```env
BOT_TOKEN=1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx
COMPANY_CONFIG=configs/beauty_studio.yaml
DATABASE_URL=sqlite+aiosqlite:///./data/booking.db
ADMIN_IDS=123456789
NOTIFY_CHAT_ID=-100123456789
TZ=Europe/Moscow
REMINDER_HOURS=2
```

### Шаг 2. Установка зависимостей
```bash
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 3. Запуск бота
```bash
python -m bot.main
```

При первом запуске база данных автоматически создаст все таблицы и загрузит категории и услуги из выбранного YAML-файла!

## 🐳 Запуск через Docker

### Один бот:
```bash
docker compose up -d --build
```

### Несколько ботов (Multi-tenant):
Используйте `docker-compose.multi.yml`. В нем определены независимые контейнеры под каждую компанию с общим исходным кодом ядра:
```bash
docker compose -f docker-compose.multi.yml up -d
```
